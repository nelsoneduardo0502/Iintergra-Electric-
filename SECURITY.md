# Seguridad — IINTEGRA ELECTRIC

Si detectas una vulnerabilidad en este sitio, repórtala de forma privada a:

**Iintegra.ventas@gmail.com**

Por favor no publiques datos de clientes, fotografías sin censura, números de serie, placas de proyecto ni pruebas de concepto que expongan información sensible.

## Alcance

Este sitio es una landing page estática. No utiliza base de datos ni backend propio. El cotizador prepara un mensaje localmente en el navegador y únicamente comparte los datos cuando el visitante decide abrir WhatsApp.

## Archivos sensibles

Nunca deben subirse al repositorio:
- fotografías originales de clientes sin censura;
- documentos, planos o diagramas confidenciales;
- contraseñas, tokens, claves API o archivos `.env`;
- respaldos del sitio que incluyan material no publicado.
